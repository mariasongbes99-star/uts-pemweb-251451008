Tentang Kegiatan

Kegiatan ini merupakan pelatihan intensif untuk membangun antarmuka website yang responsif, rapi, dan aksesibel menggunakan standar HTML5 Semantik serta tata letak CSS Flexbox. Terbuka bagi seluruh mahasiswa yang ingin memperdalam keterampilan pengembangan web front-end.

Syarat Peserta

  • Mahasiswa aktif Fakultas Sains dan Teknologi Informasi.
  • Membawa laptop pribadi dengan teks editor (VS Code) terpasang.
  • Memiliki minat belajar dasar struktur HTML dan CSS.

Alur Pendaftaran

  1. Isi data diri dengan lengkap pada formulir pendaftaran di bawah.
  2. Verifikasi kelengkapan data dan pilih divisi minat kegiatan.
  3. Klik tombol Kirim Pendaftaran untuk mendapatkan konfirmasi.
